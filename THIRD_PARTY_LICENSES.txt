1. EXECUTIVE SUMMARY & COMPLIANCE ASSURANCE
================================================================================

NemoFold is engineered under strict architectural and governance invariants:
100% Local-First, Zero-Egress by default, unprivileged user-mode execution
(RunAsInvoker), and fail-closed safety gate interception. The core agent loop
turns explicitly approved local directories into a persistent working memory,
keeps claims traceable to source locations, and makes file actions reversible.

All direct, optional, and development dependencies utilized across NemoFold
are distributed under strictly permissive and free open-source licenses (MIT,
BSD-3-Clause, PSFL-2.0). There are zero copyleft, GPL, or AGPL-style viral
dependencies, guaranteeing complete operational safety for enterprise
integration, autonomous agent fleets, and security-critical deployments.
Canonical copyright and ecosystem attributions are formally preserved in the
root NOTICE file.

3. ZERO-COPYLEFT ISOLATION GUARANTEE & RUNASINVOKER CERTIFICATION
================================================================================

1. Zero-Copyleft Isolation Guarantee:
   All core runtime dependencies operate strictly under permissive open-source
   licenses (MIT, BSD-3-Clause, PSFL-2.0). The codebase, build definitions,
   and runtime interfaces are completely free of GPL, AGPL, LGPL, SSPL, or
   reciprocal copyleft obligations.

2. Unprivileged Execution (RunAsInvoker):
   NemoFold enforces unprivileged user-mode execution under INV-RUNAS-08.
   All document parsing, SQLite FTS indexing, and local action journals operate
   strictly within non-elevated user context without requiring administrative
   elevation, root privileges, or daemon background services.

3. Fail-Closed Security & Reversible Action Defense:
   Under INV-GATE-04 and INV-ACTION-03, any ambiguous request or unmatched path
   fails closed into a structured error or operator confirmation modal.
   All file actions are pre-flight validated, logged to a transactional journal,
   and provide complete rollback and resume capabilities.
