# Three-minute jury demo

This is the recording plan, not evidence that a public video or live cloud run already
exists. Replace the marked live segment only after an approved Nebius/Nemotron run has
been captured and verified.

## 0:00–0:20 — The problem

Show the Captain Nemo console hero and say: “My useful documents are private, spread
across folders, and constantly changing. A personal assistant should remember them
without silently taking control of them.”

## 0:20–0:45 — The trust boundary

Point to Local files, Policy gate, and Nemotron. Explain that originals, paths, index,
policy, audit, and action authority stay local. Only explicitly selected,
pseudonymized chunks can cross the gate with a declared model and budget.

## 0:45–1:25 — Evidence Analyst

Select Evidence Analyst and preview the exact scope. Run the synthetic policy example.
Open the result and highlight:

- the answer to both questions;
- an exact quote with filename and line or PDF page;
- conflict hints between older and current wording;
- read, cited, unsupported, and unreadable coverage.

## 1:25–1:50 — Persistent memory

Run Folder Digest after changing or deleting one synthetic document. Show the inventory
delta and explain that source hashes update the local index and prune deleted material.
Show that a run can resume from its snapshot rather than becoming another disposable
chat.

## 1:50–2:15 — Controlled action

Preview Smart Inbox. Show the full-batch collision gate, then apply only in the prepared
synthetic directory. Display the action journal and undo receipt, and undo the move.

## 2:15–2:45 — Mandatory live platform segment

Record a real, sanitized job crossing the approved privacy gate to the actual
Nebius-hosted NVIDIA Nemotron runtime. Show the model identifier, bounded package,
response receipt, latency or usage evidence, local citation validation, and the final
run report with `transfer_performed: true` and `cloud_proof: true`.

Return to the architecture and say: “NemoFold lets model reasoning travel, but never
hands over file authority. It is a persistent personal agent whose memory, evidence,
and undo trail remain yours.”
