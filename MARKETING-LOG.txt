2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. [PERSONA-01] Local-First Knowledge Workers & Researchers
   - Needs: Extract verifiable facts, dates, and numbers from multi-format document collections (PDF, DOCX, ODT, TXT, CSV, JSON) without trusting cloud SaaS with confidential research.
   - Pain Points: Hallucinated summaries, ungrounded citations, vendor lock-in, data egress risks.
   - NemoFold Solution: Byte-exact quote matching (INV-EVID-02), SQLite FTS5 persistent memory, 100% offline zero-egress operation by default (INV-LOCAL-01).

2. [PERSONA-02] Legal, Compliance & Due Diligence Auditors
   - Needs: Track claims back to exact source documents, line numbers, and page offsets; maintain an unalterable, reproducible evidence trail.
   - Pain Points: Black-box AI outputs that cannot be defended in court or regulatory audits; lack of provenance.
   - NemoFold Solution: Cryptographic SHA-256 run ledgers (INV-DET-09), statutory disclaimer (§ 521 BGB), structured run reports, fail-closed gate verifications.

3. [PERSONA-03] Autonomous AI Agent & Tooling Engineers
   - Needs: Standardized Model Context Protocol (MCP) integration, structured tool calling, deterministic file action gates, and loopback API surface.
   - Pain Points: Uncontrolled agent file overwrites, runaway API spending, ungrounded tool responses.
   - NemoFold Solution: Official `nemofold-mcp` stdio server, loopback-only HTTP API (INV-PROV-06), multi-tier approval gates (INV-GATE-04), reversible dry-run journals (INV-ACTION-03).

4. [PERSONA-04] Privacy-Conscious Healthcare & Financial Analysts
   - Needs: Reconcile complex medication plans, invoices, and contracts on air-gapped workstations or private intranet hardware.
   - Pain Points: Elevation requirements, sensitive PII/PHI leakage, copyleft contamination in commercial environments.
   - NemoFold Solution: Unprivileged user-mode execution (INV-RUNAS-08 `RunAsInvoker`), 100% permissive dependency stack (0% copyleft), sanitized path-free export packages (INV-ISOL-05).
