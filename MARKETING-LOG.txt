1. EXECUTIVE SUMMARY & VALUE PROPOSITION
--------------------------------------------------------------------------------
NemoFold is a private, evidence-first document agent engineered with reversible
file actions, persistent working memory, exact citations, and bounded external reasoning.
Built for the Nebius x NVIDIA Global AI Hackathon and enterprise document discovery,
NemoFold transforms declared local folders into a persistent SQLite FTS5 index,
tracks all assertions down to line- and page-exact quotes, and keeps file mutations
strictly reversible via an append-only journal with preview, resume, and undo.

2. TARGET AUDIENCES & PERSONAS
--------------------------------------------------------------------------------
[PERSONA-01] Legal, Compliance & Due Diligence Analysts
  * Context: Reviewing voluminous corporate disclosures, contracts, M&A filings, and audit dossiers.
  * Pain Point: Cloud assistants ingest privileged documents into proprietary data centers without
    enforceable boundaries; LLM hallucinations fabricate contract terms without exact citations.
  * Solution: NemoFold runs 100% offline; claims require verbatim byte-exact quote verification
    matching line- and page-locators; no checkmark without a quote.

[PERSONA-02] Enterprise Privacy Officers & Knowledge Managers
  * Context: Managing confidential internal file shares, HR records, and regulated records archives.
  * Pain Point: Accidental cloud leakage risks GDPR/HIPAA penalties; unmonitored scripts alter or
    delete corporate records without rollback capability.
  * Solution: Strict local-first privacy boundary with path-free sanitized packaging; reversible
    file actions backed by cryptographic SHA-256 journals with preview, resume, and instant undo.

[PERSONA-03] Autonomous Agent & Local LLM Developers
  * Context: Building local-first tool chains, MCP integrations, and offline reasoning agents with
    Ollama, LM Studio, Nemotron, or Claude Code.
  * Pain Point: Agent frameworks bundle bloated abstractions, leak host paths into model prompts,
    and lack reproducible benchmark run ledgers.
  * Solution: Clean stdio MCP server (`nemofold-mcp`), provider-neutral adapter core, bounded job
    budget enforcement, loopback-only APIs, and reproducible Nebius Token Factory run proofs.

[PERSONA-04] Investigative Journalists, Researchers & Evidence Curators
  * Context: Analyzing unstructured leak archives, research corpuses, and multi-source document batches.
  * Pain Point: Manual cross-referencing across PDF, DOCX, and scanned logs is tedious; existing tools
    silently drop duplicates or hide disagreement between conflicting versions.
  * Solution: 34 specialized workflows including Fact Distill (retains omitted duplicates in an appendix),
    Synopsis Merge (surfaces disagreements as explicit conflict blocks), Reference Check, and Rater Race.

6. GOVERNANCE & RUNTIME INVARIANTS (INV-LOCAL-01 TO INV-SLA-10)
--------------------------------------------------------------------------------
- INV-LOCAL-01: 100% Local-First & Zero-Egress Default. Original files, absolute paths,
  indices, and journals remain strictly local on host without outbound telemetry.
- INV-EVID-02: Byte-Exact Evidence Citation. Assertions accepted only when verbatim
  quotes match source text byte-for-byte; line and page locators preserved.
- INV-ACTION-03: Reversible File Actions & Journaled Undo. Mutations execute with
  pre-flight dry-run, atomic commit, and full reversible undo and resume via run journal.
- INV-GATE-04: Multi-Tier Explicit Approval Gates. File actions, external model transfers,
  cloud spend ceilings, and network exposure require explicit operator flags.
- INV-ISOL-05: Path-Free Sanitized Packaging. Outbound packages strip host paths, secrets,
  symlinks, and unapproved files; preflight validates package before network transit.
- INV-PROV-06: Provider-Neutral Loopback Surface. Pluggable local and remote backends;
  unauthenticated interfaces and Captain's Desk restricted strictly to loopback (127.0.0.1).
- INV-POLICY-07: Composable Primitives & Voyages. 4 shared primitives compose 34 document
  workflows; reusable voyage drafts adapt without model fine-tuning.
- INV-RUNAS-08: Unprivileged User-Mode Execution. Operates entirely under standard user
  privileges (`RunAsInvoker`); zero system daemon or administrative elevation required.
- INV-DET-09: Deterministic Artifacts & Ledgers. Deterministic SVG figures, structured reports,
  and cryptographic SHA-256 run ledgers guarantee reproducible audit trails.
- INV-SLA-10: 48h Security & Triage SLA. Security vulnerability disclosures acknowledged
  within 48h; triage and remediation assessment completed within 5 business days.
